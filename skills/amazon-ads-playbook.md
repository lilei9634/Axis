# 亚马逊广告操作手册

## 关键指标
- ACOS = 广告花费 / 广告销售额；ROAS = 1 / ACOS。
- TACoS = 广告花费 / 总销售额，衡量产品对广告的依赖程度。TACoS 持续下降说明自然流量在增长。
- CVR = 广告订单 / 点击；CPC = 花费 / 点击。

## 搜索词处理
- **否定**：点击数达到阈值（默认 15）或花费达到阈值（默认 10）仍然 0 出单的搜索词，在对应广告活动里否定精准。与产品明显不相关的词，点击数少也可以直接否定。
- **收割**：自动、广泛或词组匹配中出单 ≥2、ACOS 低于目标 70% 的搜索词，加到手动精准广告活动里，初始出价参考该词的历史 CPC；同时在原广告活动中否定精准，避免两边互相抢量。
- 品牌词和竞品 ASIN 定位要分开管理，不要和通用词混在一个广告活动里。

## 出价调整
- 每次调价幅度不超过 ±30%，避免排名剧烈波动。
- ACOS 高于目标 1.5 倍且点击充足的投放：目标出价 ≈ 当前 CPC × 目标 ACOS / 当前 ACOS，向下取整。
- ACOS 远低于目标且曝光不足的投放：出价提高 10%-20%，争取更多曝光。
- 数据不足（点击少于 10 次）的投放不要轻易下结论。

## 预算
- 预算受限（日均花费 ≥ 预算 95%）且 ACOS 健康的广告活动：预算提高 20%-30%。
- ACOS 持续超标的广告活动先优化投放和出价，不要直接加预算。
- 产品库存不足时，相关广告活动要降低预算或降低出价，保护库存。

## 新品期与成熟期
- 新品期（上架 < 60 天）可以接受更高的 ACOS 来换取排名和评论，目标 ACOS 可以放宽到 1.5 倍。
- 成熟期以利润为导向，严格控制 ACOS 和 TACoS。
