# 单品诊断 SOP

用于对一个在售产品做全面体检，输出一份可以直接审批执行的优化方案。

## 诊断框架
按顺序检查，每一项都要给出现状（数字）、判断（正常 / 问题）、原因推测：

1. **销售趋势**：近 30 天逐日销量和销售额，近 7 天与前 7 天对比。有没有断崖式下滑或持续下滑？
2. **流量**：Sessions 的趋势。流量下降通常意味着排名下滑、广告减量或季节性变化。
3. **转化**：转化率（销量 / Sessions）的趋势。转化下降通常与价格、差评、评分、Listing 质量、Buy Box、竞品促销有关。
4. **广告结构**：有没有自动 + 手动精准的基本结构？广告活动是否太少或太乱？
5. **广告效率**：整体 ACOS、TACoS；花费最高的投放词和搜索词效率如何；有没有浪费和收割机会。
6. **库存**：可售天数，是否需要补货，补货前是否需要控制广告。
7. **Listing 质量**：标题、五点、图片数量、A+、评分和评论数，参照 Listing 优化规范逐项检查。

## 输出要求
- summary：这个产品当前处在什么状态（健康 / 需要优化 / 需要抢救），最关键的 1-2 个问题是什么。
- findings：按诊断框架逐项写，每项一条。
- recommendations：按"止损 → 提升转化 → 提升流量 → 长期优化"的顺序排列；Listing 修改建议要给出具体的改写方向。
- questions_for_owner：采购成本、头程费用、利润率、竞品情况等系统里没有的信息。
